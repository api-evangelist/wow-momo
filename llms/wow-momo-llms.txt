## What is actually callable

- [WOW! Momo Content API](https://www.wowmomo.com/wp-json/): the live WordPress REST API behind
  www.wowmomo.com. Anonymous, no key, no registration. 20 operations answer without a credential: the
  site's 6 pages, 98 media items, 5 categories, 15 tags, 1 author, the post-type/taxonomy/status
  registries, a cross-type search index of 7 objects, an oEmbed 1.0 provider endpoint and the Yoast SEO
  head document. Its route index declares 396 routes across 36 namespaces; everything not listed above is
  administrative and returns 401 or 403.
- [WOW! Momo App Backend](https://api.wowmomo.com/): the backend of the Wow Eats consumer ordering app.
  NOT callable. Every path probed anonymously on 2026-09-04, including a control path that cannot exist,
  returned HTTP 200 with the identical body {"data":null,"message":"NO_AUTH","messageType":"FAILED"}.
  Only GET /health answers, with "OK". Note the gate returns 200, not 401 — status-code-based error
  handling will read a rejected call as a success with a null payload.

## Operating notes

- Send a full browser User-Agent. www.wowmomo.com runs mod_security and answered a request sent with the
  User-Agent "Mozilla/5.0" with HTTP 406.
- Errors use the WordPress envelope {code, message, data.status}, not RFC 9457 problem+json. Branch on
  `code`.
- No rate limit is documented or signalled on the wire. Be conservative.
